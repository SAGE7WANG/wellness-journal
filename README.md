# 起居注 · Daily Wellness Journal

一个单文件的健康生活日志网页。记录每日饮水、三餐热量、睡眠、运动与加班时长，自动生成趋势图表与健康提示，帮你看清自己的作息与饮食节奏。

**不用安装、不用构建、不联网、不上传数据** —— 双击 `index.html` 就能用，所有记录只保存在你自己的浏览器里。

## 功能

**记录**

| 模块 | 内容                                                                                               |
| ---- | -------------------------------------------------------------------------------------------------- |
| 饮水 | 杯子快捷按钮一键记录（150/250/350/500/750 ml）或自定义毫升数，环形进度显示达标情况                 |
| 饮食 | 早/午/晚/加餐分开记账。内置 88 种常见食物，选食物 + 填克数自动算热量；也可手动输入，记录后就地修改 |
| 睡眠 | 按「就寝/起床时间」自动算时长（支持跨零点），或直接填时长；另有午休与睡眠质量                      |
| 运动 | 30 种运动内置 MET 值，按「时长 × 强度 × 体重」估算消耗，并给出 WHO 每周 150 分钟的进度             |
| 加班 | 按起止时间或直接填时长，附可选事由；显示「标准工时 + 加班 = 当日总工时」，超上限时高亮提醒         |
| 体征 | 体重（自动对比上次变化）、今日状态、每日随笔；身高体重年龄性别用于估算基础代谢                     |

**查看**

- 近 7 / 14 / 30 天六张图表：饮水趋势、热量收支（摄入柱状 + 总消耗折线）、睡眠时长、运动时长、加班时长、体重趋势，均带目标线或上限线，鼠标悬停可看当天数值
- 指标条：平均饮水、平均摄入、平均总消耗、热量净差、平均睡眠、本周运动、本周加班、记录天数与连续天数
- 自动洞察：根据真实数据生成提示，例如「平均睡眠 6.4 小时，明显不足」「本周运动 197 分钟，已达到 WHO 建议量」

**管理**

- 目标设定：饮水、摄入热量、睡眠、运动、加班上限，以及用于估算基础代谢的身体信息
- 数据管理：导出 JSON 备份 / 导出 CSV 表格（带 BOM，Excel 直接打开不乱码）/ 导入恢复 / 清空

## 使用

直接双击 `index.html`，用 Chrome、Edge、Firefox 打开即可。

如果你的浏览器禁止本地文件使用本地存储（部分版本的 Safari 会如此），页面顶部会给出提示，此时用一个本地服务打开：

```bash
cd 项目目录
python3 -m http.server 8000
# 然后访问 http://localhost:8000/index.html
```

注意：不同打开方式的存储是**互相隔离**的（`file://` 与 `http://localhost` 各存一份），请固定用同一种方式，避免以为数据丢了。

## 数据说明

- 数据保存在浏览器的 localStorage（键名 `wellness.journal.v1`），**不会上传到任何服务器**，页面里没有任何网络请求代码。清理浏览器数据、换浏览器或换设备都会导致数据不可见，建议定期在「数据管理」中导出 JSON 备份。
- 食物热量为常见食物的每 100g 参考值，属于近似数据，实际会因品种、部位与烹饪方式不同而变化，可在记录时就地修改。
- 基础代谢用 Mifflin-St Jeor 公式估算；运动消耗按 MET 值估算；「总消耗 = 基础代谢 + 运动消耗」，不含日常活动与食物热效应，实际消耗会略高。
- 「每日加班上限」用于提示而非考核，超出时以醒目颜色提醒，不计入完成度评分。

## 技术说明

- 单个 `index.html`，HTML + CSS + 原生 JavaScript，无框架、无依赖、无构建步骤
- 图表与进度环全部用手写 CSS / 内联 SVG 实现，因此完全离线可用
- 适配桌面与移动端，跟随系统「减少动态效果」设置
- 用户输入在插入页面前统一转义；导入的 JSON 属于外部输入，同样经过转义与日期格式校验

## 浏览器支持

Chrome / Edge 90+、Firefox 90+、Safari 15+。用到了 CSS 自定义属性、`backdrop-filter`、内联 SVG 等特性；若浏览器不支持日期选择器的 `showPicker()`，顶部日期跳转会自动降级为内联日期输入框。
